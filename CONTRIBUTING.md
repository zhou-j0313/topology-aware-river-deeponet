# Contributing

Contributions that improve documentation, portability, tests, or baseline
implementations are welcome.

1. Create a focused branch from `main`.
2. Keep input schemas backward compatible or document the migration.
3. Add or update tests for behavior changes.
4. Run `python -m pytest` before opening a pull request.
5. Do not commit private measurements, credentials, solver binaries, generated
   work directories, or data that you are not authorized to redistribute.

Please use the issue tracker for reproducible bug reports and include the Python,
PyTorch, operating-system, and hardware versions.
